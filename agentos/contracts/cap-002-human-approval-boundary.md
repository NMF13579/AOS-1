# CAP-002 Human Approval Boundary Contract

PASS is not approval.
Evidence is not approval.
CI PASS is not approval.
Readiness is not approval.
Completion review is not approval.
Agent report is not approval.
Agent self-claim is not approval.

Human approval cannot be simulated.
Missing approval must block.
Ambiguous approval must block.
Agent-generated approval must block.

The contract must define that only traceable human-originated approval evidence may satisfy the boundary.

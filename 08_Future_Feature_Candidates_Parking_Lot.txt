## 1. Назначение

Этот документ хранит будущие feature candidates, чтобы не потерять идеи и не раздувать Stage 1.

Parking lot не является:

- roadmap;
- approval;
- implementation plan;
- milestone plan;
- execution permission;
- feature admission decision;
- source of truth для текущей реализации.

## 2. Главная граница

```text
Future feature candidate ≠ roadmap item.
Parking lot ≠ approval.
Research idea ≠ core requirement.
Deferred feature ≠ active scope.
Mentioned feature ≠ permission to build.
```

Фича может выйти из parking lot только через human checkpoint, roadmap update или explicit task brief.

## 3. Allowed statuses

Разрешённые статусы:

```text
DEFERRED
RESEARCH_ONLY
REJECTED_AS_CORE_DEFAULT
NEEDS_HUMAN_ARCHITECTURE_DECISION
UNKNOWN_BLOCKED
```

Запрещённые статусы:

```text
CORE_REQUIRED
IMPLEMENTATION_READY
APPROVED
READY_TO_BUILD
AUTO_ADMITTED
```

## 6. Promotion rule

Before promotion, a candidate needs human review of:

- target layer;
- risk class;
- source-of-truth impact;
- approval boundary;
- lifecycle boundary;
- validation/negative-case need;
- implementation scope.

This document does not need to store exact promotion fields. Exact promotion format belongs to a future task brief or validator.

## 7. Forbidden claims

Forbidden claims:

```text
This feature is approved.
This feature is ready to implement.
This feature is part of Stage 1.
This feature is required for current transfer.
This feature can start automatically.
This feature has human approval because it is listed here.
```
